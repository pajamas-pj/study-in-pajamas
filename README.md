Study_in_Pajamas 在线教育服务平台

技术栈

微服务架构：Spring Cloud Alibaba (Nacos, Sentinel, Gateway, OpenFeign), Spring Cloud LoadBalancer
分布式组件：Redisson, RabbitMQ, XXL-JOB, Seata
数据存储：MySQL, Elasticsearch, Redis
容器与运维：Docker, Jenkins
开发工具：Apifox, Gitee

项目亮点

 **微服务架构与网关设计 (Gateway & Common & Api )** 
-动态网关与安全认证：基于 Spring Cloud Gateway 搭建统一流量入口，利用 Nacos  搭配监听器实现动态路由。设计基于 GlobalFilter 的全局认证机制，采用 JWT 双令牌结合 RS256 非对称加密策略，实现无感刷新与主动下线。
-服务治理与组件封装：基于 Sentinel 实现请求限流、线程隔离与熔断降级，保障系统稳定性。封装 OpenFeign 日志、Fallback等基础组件，搭配 OkHttp 连接池与 LoadBalancer 负载均衡器，并设计 ThreadLocal 上下文拦截器，实现用户信息的跨服务透传。
 **Learn** 
描述：在线学习核心模块，涵盖课程管理、学习记录归档、进度追踪、互动问答、用户签到及积分排行。重点解决了高并发场景下的学习进度实时保存、海量学习记录的统计分析以及赛季积分的实时排行与持久化问题。
-高并发进度异步持久化：针对视频播放下的高频进度上报，设计“Redis缓存+延迟队列”的双重缓冲机制。利用 Redis 缓存合并写请求，结合 DelayQueue 实现每20秒的异步延迟持久化进度数据。
-海量数据排行与分库分表：采用 Redis ZSet 实现本赛季积分实时排行，支持高并发读写场景。针对历史数据设计分库分表策略，集成 MyBatis-Plus 动态表名插件搭配定时任务完成建表、持久化与异步数据清除。利用 XXL-JOB 解决单机定时任务在多实例部署时缺陷，采用分片广播路由策略配合多实例分页拉取 Redis 数据，实现海量榜单数据的并行持久化入库。
-复杂统计与全文检索：优化复杂统计场景，利用 MyBatis-Plus 构建查询条件，通过 ew.customSqlSegment 复用动态查询逻辑实现聚合统计，避免 XML 中冗余的 SQL 拼接。集成 Elasticsearch 建立课程与问题的索引关联，支持管理端根据课程名称检索问题。
-用户互动与高效签到：封装积分类型枚举，通过全局枚举处理器规范化状态映射，将业务场景与上限规则绑定，基于 RabbitMQ 异步解耦积分变更。利用 Redis BitMap 实现用户月度签到功能，通过位运算高效计算连续签到天数。
 **Promotion** 
描述：营销核心模块，涵盖优惠券全生命周期管理，支持多种领取方式，实现优惠券使最优方案推荐。重点解决高并发秒杀场景下的库存一致与限量核销、复杂优惠券规则下的最优组合试算难题、单机与分布式环境下的锁失效与事务失效问题、设计海量兑换码的高效生成与校验，以及多策略并行计算的异步任务优化。
-高性能兑换码生成：设计轻量级兑换码生成算法，采用“加权校验位+序列号”结构并通过Base32编码，防止暴力破解；利用 Redis BitMap 进行核销状态标记，结合 String 原子自增生成唯一序列，在仅占用 512MB 空间的情况下支撑超10亿量级兑换码；引入异步线程池批量生成，确保兑换码具备短小、防重、防刷、高效、高可用特性。
-自定义分布式锁组件：针对集群环境下的传统分布式锁缺陷，基于 Redisson + AOP + SPEL 封装自定义分布式锁注解，结合工厂模式与策略模式实现环绕增强，支持 4 种模式 5 种策略，实现了业务代码与锁逻辑的非侵入式解耦。
-高并发领券架构设计：针对秒杀场景下的超卖与并发安全问题，设计基于 Redis + Redisson 分布式锁的库存扣减与限量校验方案，实现校验逻辑完全脱离数据库，搭配 MQ 消息与乐观锁优化实现安全的异步下单。
-智能优惠计算引擎：基于策略模式实现 4 类折扣规则，利用回溯算法完成多优惠券排列组合。引入 CompletableFuture 与线程池实现多规则并行计算，配合 CountDownLatch 进行任务聚合，并采用 SynchronizedList 保证线程安全，实现了高效的最优方案推荐。
 **Remark** 
-设计并实现通用点赞业务，基于 Redis Set 管理用户点赞记录，利用 ZSet 聚合点赞计数；通过定时任务批量读取增量数据并投递 MQ 消息，异步通知业务服务更新冗余计数。

项目模块

1. 架构与网关 (pj-gateway & pj-common & pj-api & pj -user)
-基于 Nacos 进行服务注册与发现、共享配置管理、配置热更新，编写监听器，支持动态修改路由配置。
-针对 WebFlux 的响应式编程，基于 GlobalFilter 实现统一认证逻辑，构建灵活白名单匹配机制对公共接口自动放行，并将用户信息透传至下游。
-采用 RS256 算法实现公私钥分离机制，网关仅持有公钥进行本地验签。降低密钥泄露风险，避免了远程校验带来的性能损耗。
-实现 JWT 双令牌 校验，基于 Access、Refresh 分离策略，结合 Redis 实现令牌轮换、无感刷新，支持主动下线。
-抽取公共 API 模块管理 FeignClient，基于 OpenFeign 声明式调用，引入 OkHttp 连接池与 LoadBalancer 负载均衡器，自定义 FeignLogger 拦截器支持日志输出。
-引入 Sentinel 构建服务保护体系，配置 QPS 限流、信号量隔离、熔断保护、降级处理fallback等功能
-设计请求上下文拦截器HandlerInterceptor，解析网关透传的用户信息并存入ThreadLocal。
2. 学习中心 (pj-learning)
描述：在线学习核心模块，涵盖课程管理、学习记录归档、进度追踪、互动问答、用户签到及积分排行。重点解决了高并发场景下的学习进度实时保存、海量学习记录的统计分析以及赛季积分的实时排行与持久化问题。
-基于 RabbitMQ 监听交易支付消息，异步构建课表数据，支持一次性购买多门课程。
-设计学习状态、学习记录管理，通过全局枚举处理器规范化状态映射，支持多维度查询最近学习课程、本周计划及实时进度。
-编写基于 GROUP BY 与聚合函数的复杂统计 SQL，按课程分组计算用户在指定时间窗口内的已完成小节数，利用自定义 DTO 接收映射结果
-针对视频播放下的高频进度上报，设计“Redis缓存+延迟队列”的双重缓冲机制。利用 Redis 缓存合并写请求，结合 DelayQueue 实现每20秒的异步延迟持久化进度数据。
-实现用户端用户提问、回答、评论功能，支持匿名发布机制。
-实现管理端问题、回答、评论功能，支持对违规内容的隐藏与显示、问题，集成 Elasticsearch 建立课程与问题的索引关联，支持根据课程名称、查看状态检索问题。
-利用 Redis BitMap 结构实现用户月度签到功能，结合位移运算高效计算连续签到天数。
-封装积分类型枚举，将业务场景与积分上限规则绑定；基于 RabbitMQ 异步解耦业务动作与积分变更
-利用 MyBatis-Plus QueryWrapper 构建查询条件，通过 ${ew.customSqlSegment} 复用动态查询逻辑实现聚合统计，避免 XML 中冗余的 SQL 拼接。
-采用 Redis ZSet 实现本赛季积分实时排行，支持高并发读写场景
-针对历史数据设计分库分表策略，集成 MyBatis-Plus 动态表名插件搭配ThreadLocal传递表名，通过定时任务在赛季结束后建表、持久化并基于 unlink 命令异步清除数据
-利用 XXL-JOB 解决单机定时任务在多实例部署时缺陷，采用分片广播路由策略配合多实例分页拉取 Redis 数据，实现海量榜单数据的并行持久化入库
3. 营销核心 (pj-promotion)
描述：营销核心模块，涵盖优惠券全生命周期管理，支持多种领取方式，实现优惠券使最优方案推荐。重点解决高并发秒杀场景下的库存一致与限量核销、复杂优惠券规则下的最优组合试算难题、单机与分布式环境下的锁失效与事务失效问题、设计海量兑换码的高效生成与校验，以及多策略并行计算的异步任务优化。
-设计轻量级兑换码生成算法，采用“加权校验位+序列号”结构（模仿JWT签名机制）并通过Base32编码，防止暴力破解；利用 Redis BitMap 进行核销状态标记，结合 String 原子自增生成唯一序列，在仅占用 512MB 内存的情况下支撑 2^32（超10亿）量级数据去重；引入异步线程池批量生成，确保兑换码具备短小（<10位）、防重、防刷、高效、高可用特性。
-针对优惠券领取的并发问题，初步通过乐观锁解决库存超卖问题，基于 Synchronnized 锁解决限领数量校验，结合Aspectj 解决事务失效并调整事务与锁顺序解决单机模式锁失效问题，基于 Redis SETNX 实现简单分布式锁集群模式下锁失效问题。
-进阶结合 Redisson 和 AOP 实现基于注解的分布式锁改造实现环绕增强，并结合工厂模式、策略模式、SPEL表达式实现优雅的分布式锁功能，解决锁误删问题以及简单分布式锁的多种问题。
-高级优化通过加入优惠券缓存，实现基于 Redis 的库存与限领校验以及兑换码目标校验，所有校验脱脱离数据库发送MQ消息实现异步领券，支持手动领取与兑换码兑换功能
-采用策略模式隔离优惠券折扣业务规则，利用回溯算法解决优惠券排列组合难题，引入 CompletableFuture 进行异步并行计算，配合 CountDownLatch 实现任务聚合，采用 SynchronizedList 保证线程安全，支持范围限定，优惠计算，叠加最优解，实现了高并发下的快速试算与最优优惠方案推荐。
4. 用户互动 (pj-remark)
-设计并实现通用点赞业务，基于 Redis Set 管理用户点赞记录，利用 ZSet 聚合点赞计数；通过定时任务批量读取增量数据并投递 MQ 消息，异步通知业务服务更新冗余计数。
